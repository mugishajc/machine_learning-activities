  Using the whole-data median means each validation fold is imputed with a value
  that was computed partly from itself. The validation rows contributed to the
  statistic used to fill them, so they are no longer unseen. The same argument
  applies to StandardScaler, whose mean and standard deviation are estimated the
  same way, and the effect grows as the statistic becomes more sensitive to
  individual rows: a median barely moves, a maximum moves entirely.

  preprocessing fitted on everything, then cross-validated : ROC AUC 0.9097
  preprocessing inside the pipeline, re-fitted per fold     : ROC AUC 0.9097
  difference -0.0000
  A Pipeline prevents this because cross_val_score calls fit() on the whole
  pipeline separately for each fold, so every transformer learns its parameters
  from that fold's training rows alone and applies them unchanged to the held-out
  rows. ColumnTransformer carries the same guarantee across all three branches at
  once, so nothing has to be remembered by hand.

4. THE SIZE OF THE LEAK DEPENDS ON THE STATISTIC AND THE SAMPLE
  median + StandardScaler                n=   200   leaked 0.8606   clean 0.8617   gap -0.0011
  median + StandardScaler                n= 1,000   leaked 0.9274   clean 0.9275   gap -0.0001
  median + StandardScaler                n= 5,000   leaked 0.9037   clean 0.9036   gap +0.0000
  median + StandardScaler                n=20,000   leaked 0.9101   clean 0.9101   gap +0.0000

  median + MinMaxScaler                  n=   200   leaked 0.6106   clean 0.6106   gap +0.0000
  median + MinMaxScaler                  n= 1,000   leaked 0.7751   clean 0.7829   gap -0.0078
  median + MinMaxScaler                  n= 5,000   leaked 0.8977   clean 0.8978   gap -0.0002

  StandardScaler uses a mean and a standard deviation, both averages over every
  row, so removing a fifth of them barely moves either and the leak stays small.
  MinMaxScaler uses the minimum and maximum, each determined by a single row, so
  one extreme validation value rescales the entire column. The rule to teach is
  not that leakage is always large, but that its size tracks how much a single
  observation can move the statistic being fitted.
